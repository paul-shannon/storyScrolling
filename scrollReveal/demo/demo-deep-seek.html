🔍 ScrollReveal.js Interactive Demo

Scroll down this page to see various animation effects triggered by the ScrollReveal library. Each colored box below has a different configuration.

1. Basic Default Animation

The default animation fades elements in from the bottom as you scroll[citation:1][citation:5].

Default: Fades up from bottom
JavaScript Code:
ScrollReveal().reveal('.sr-default');

2. Custom Origin & Distance

You can control the direction and distance of the animation[citation:2][citation:5].

From Left - 100px
From Right - 150px
JavaScript Code:
ScrollReveal().reveal('.sr-left', { distance: '100px', origin: 'left', duration: 1000 }); ScrollReveal().reveal('.sr-right', { distance: '150px', origin: 'right', duration: 1200 });

3. Rotate & Scale Effects

Elements can also rotate and scale as they enter the viewport[citation:5].

Rotating Element
Scaling Element
JavaScript Code:
ScrollReveal().reveal('.sr-rotate', { rotate: { x: 20, y: 20, z: 5 }, duration: 1500 }); ScrollReveal().reveal('.sr-scale', { scale: 0.5, duration: 1200 });

4. Sequential Animations

You can stagger animations for multiple elements using the interval option[citation:2][citation:5].

Sequence Item 1
Sequence Item 2
Sequence Item 3
JavaScript Code:
ScrollReveal().reveal('.sr-seq', { interval: 200, // 200ms between each element's start origin: 'bottom' });

5. Reset on Scroll & Mobile Control

Configure if the animation replays (reset) and whether it works on mobile[citation:5][citation:7].

Animates each time you scroll past
JavaScript Code:
ScrollReveal().reveal('.sr-reset', { reset: true, // Animation replays when element leaves/re-enters view mobile: true // Enable animations on mobile devices });
