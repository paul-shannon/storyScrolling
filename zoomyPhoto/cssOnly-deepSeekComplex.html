Zoomed Image - Top-Right Quadrant (Corrected)

How it works:

This image is zoomed 2x and shows only the top-right quadrant.

CSS Properties:

transform: scale(2); - Zooms the image 2x

transform-origin: 100% 0%; - Sets the zoom origin to the top-right corner

The red lines show the quadrants. We're showing only the top-right section.

Why this works: When we scale from the top-right corner, the image expands in all directions from that point. Since the container hides overflow, we only see the part that fits in the container - which is the top-right quadrant.
